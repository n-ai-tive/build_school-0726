## Headings and Text Formatting

```
# H1
## H2
### H3
#### H4
##### H5
###### H6

Normal text paragraph.

*italic* or _italic_
**bold** or __bold__
***bold italic***
~~strikethrough~~

Manual line break: add two spaces to the end of the line  
like this
```

## Lists and Quotes

```
- Bullet item
- Another item
- Item with **bold** text

1. First item
2. Second item
3. Third item

> Blockquote line
> Second line of quote
```

## Links, Images, Code

```
[link text](https://example.com)
[link with title](https://example.com "Title")

![alt text](path/to/image.png)

Inline `code` in a sentence.

```python
def hello(name: str) -> None:
    print(f"Hello, {name}")
```

## Extras (extended formatting)

```
- [x] Completed task
- [ ] Incomplete task

==highlighted text==    <!-- some renderers only -->
H~2~O                    <!-- subscript -->
X^2^                     <!-- superscript -->

Footnote example.[^1]

[^1]: Footnote text here.
```
