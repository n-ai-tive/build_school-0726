Build School will focus on the Anthropic's Claude family of tools, but all the major labs / companies offer similar "products"  

- **Chat** is about thinking and exploration  - smart friend - Chat excels when you need to ask questions, brainstorm, draft, or work through problems back and forth - ideas are the output
- **Cowork** is about doing - good assistant (careful with permissions) - built for work that takes real effort: pulling information from many sources, making sense of it, and producing something finished - Cowork can Access folders, Schedule Tasks, Spin Up Sub-Agents, Dispatch from your phone, make Project Folders, use your web browser, use your Computer, run Plugins, can be Limited to specific Environments / file access - docs, reports etc. are the output
- **Code** is about building - friend who is an engineer - Claude Code, runs directly inside the desktop app. It gives you a full development environment for building software - an app or experience is the output
- **Design** is about making it look nice - friend who is a designer - a design system, logo, brand is the output

## Different Models Sizes

Each of the big frontier labs offers multiple models  that differ in size. The size of the model refers to the number of parameters it contains. The more parameters, the more compute power it uses to operate.  As you begin to use the AI tools more and more, this becomes an issue because you're charged based on how much compute power you use. So, the good way to think about it is:

- For simple tasks, like reviewing and understanding simple text inputs, it's better to use small, lightweight models. 
- For more complex tasks, like solving problems or thinking through a design challenge,  use the bigger models.
